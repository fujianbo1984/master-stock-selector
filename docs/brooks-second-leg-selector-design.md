# Brooks 强势股—H1 独立观察池设计

## 1. 产品目标

本方法与 Weinstein、Minervini 完全独立，只回答三个问题：

1. 哪些沪深普通 A 股今天首次形成高质量强势第一腿；
2. 哪些股票在首次触发后处于 B1 延伸、回调等待、跟随上涨或本轮 H1 已过阶段；
3. 哪些股票今天出现了某轮回调后的第一次 H1 向上尝试。

系统缩小观察范围，不预测收益、不生成自动买卖指令，也不进入“两法同时符合”交集。
回调是否充分、是否符合用户理解的 touch25，由用户结合页面数据人工判断。

## 2. 冻结边界

- 股票范围：沪深普通 A 股；排除北交所、ST、停牌、非上市状态和信号日一字涨停。
- 复权：前复权价格计算形态；原始价格判断涨停和次日可成交性。
- 最少历史：信号日前至少 133 根有效日线。
- 第一腿窗口：3、5、8 个交易日。
- 第一腿幅度：至少 3 ATR；ATR20 只使用信号日前 20 个完整真实波幅。
- 路径效率不低于 0.75。
- 阳线实体不少于窗口的 60%，且至少 2 根。
- 平均收盘位置 CLV 不低于 0.65。
- 平均相邻 K 线重叠不高于 0.35。
- 信号日前 20 日成交额中位数不少于 2,000 万元。
- 同一股票首次触发事件冷却 40 个交易日；事件最多跟踪 40 个交易日。

第一腿速度、超过门槛的额外 ATR、H2、通道、缩量、振幅收缩、其他大师方法和市场状态均不加分。

## 3. 首次触发与 B1 冻结

对每个收盘日分别检查 3、5、8 日窗口。同日多个窗口合格时只保留最长窗口。
首次触发窗口和信号日是不可变事实，不代表整轮行情最终只上涨这些天。

触发后系统只在首次收盘回调前更新 B1：

- B1 最高收盘价与 B1 范围内最高价；
- B1 实际起止日期和交易日数；
- B1 ATR 幅度和完整路径事实；
- 最大连续收涨区间；
- 当前回调比例、盘中最大回调、回调 ATR、天数和低点。

触发后首次出现 `close < b1_peak_close` 时，该日开启第一轮回调，B1 冻结在上一峰值且永久不变。回调日的盘中高点不进入 B1。收盘等于当前 B1 峰值时仍属于 B1；终点移至该日。

B1 冻结后的新高只更新跟随周期峰值，用于结束当前回调并准备后续周期；不得反写 B1 的终点、跨度、幅度或质量事实。touch25 不参与 B1 冻结。

## 4. 回调周期与 H1

### 4.1 回调周期

首次回调以 B1 冻结峰值为锚点；后续回调以各自的跟随周期峰值为锚点。必须至少存在一个已经完成的回调交易日，下一交易日起才允许产生 H1。

回调周期持续到以下任一事件：

- 收盘创出新的周期峰值：本轮结束，更新跟随周期峰值，B1 不变；
- 第一腿结构失效：事件终止；
- 事件超过 40 个交易日：事件超时。

### 4.2 H1 日线代理

回调周期中的第一根同时满足以下条件的日 K，记录为该轮 H1：

- 第一腿结构仍有效；
- `close > open`；
- 当日 `CLV >= 0.65`；
- `high > previous_day_high`。

一轮回调只记录第一次 H1。即使后面再次出现同类 K 线，也不会在同一轮重复生成；只有收盘创新高并开启下一轮回调后，才可能产生新的 H1。

H1 发生日保存 `h1_date = as_of_date`。后续每日事实不复制旧 H1 日期；历史查询使用 `as_of_date = h1_date`，因此一个 H1 只出现一次，不会因后续每日快照重复计数。

H1 是观察事件，不是买点。H1 日收盘时次日状态为 `PENDING`，不得使用下一交易日信息反写当日事实。

## 5. touch25 人工判断

touch25 不再是自动状态、门槛或排序条件。系统只展示客观输入：

- 收盘回调占第一腿比例；
- 盘中最大回调比例；
- 回调 ATR；
- 回调交易日数；
- 回调低点；
- 第一腿起点与前高；
- H1 当日 CLV 和突破前一日高点幅度。

用户据此人工判断回调是否充分。人工结论不写入公共行情事实，也不改变 H1 的发生日期。

## 6. 页面查询合同

页面默认进入“优先观察”。主观察链为“今日B1触发 → B1延伸 → 回调观察 → 今日 H1 → 跟随上涨”，历史 H1 独立保留。

| 查询 | 条件 |
| --- | --- |
| 优先观察 | H1 重点观察且第一腿路径效率≥0.85、CLV≥0.75、重叠≤0.30 |
| H1 重点观察 | 本轮尚无 H1；回调2–10日、盘中最大回调15%–50%、回调0.5–3 ATR |
| 回调未成熟 | 本轮尚无 H1；首个回调日，或盘中最大回调不足15%，或回调不足0.5 ATR |
| 深回调/老化 | 本轮尚无 H1；盘中最大回调≥50%，或回调≥3 ATR，或回调超过10日 |
| 今日 H1 | `as_of_date = h1_date = 查询日` |
| 今日新强势 | `signal_date = as_of_date = 查询日` |
| B1延伸 | 当前 `S0_IMPULSE`，B1 尚未出现首次收盘回调 |
| 跟随上涨 | B1 已冻结，当前没有活动回调，周期峰值可继续更新 |
| 本轮 H1 已过 | 当前回调周期已经记录 H1，等待收盘创新高后开启下一周期 |
| 历史 H1 | 最近 N 个事实日中 `as_of_date = h1_date` |

以上阶段互斥。“回调观察”是回调未成熟、H1 重点观察与深回调/老化的合计；“优先观察”只是 H1 重点观察的透明质量子集，不是综合评分，不改变 H1 或 touch25 定义。

指定日期不存在 Brooks 事实时必须明确显示“尚未生成”，禁止自动回退到之前日期。

历史 H1 按发生日倒序，一轮回调只出现一行。行业、成交额和股票搜索只改变展示范围，不改变方法事实。

## 7. 数据与版本

策略版本：`brooks-strong-h1-daily-v4`。

继续复用三张不可变公共事实表：

- `brooks_impulse_event`：首次强势触发事件；
- `brooks_second_leg_daily_fact`：每日结构事实和 H1 发生日；
- `brooks_run_receipt`：运行范围、策略版本、来源摘要和计数。

旧 v1/v2.1/v3 数据继续保留，但页面和日常运行只读取当前策略版本。新版本可在同一日期追加，不覆盖历史策略事实。

`evidence_json` 分开保存不可变 B1、可变跟随周期和 H1 证据，包括：

- `trigger_window_bars`、`trigger_date`；
- `b1_anchor_date`、`b1_first_bar_date`、`b1_end_date`、`b1_bars`；
- `b1_anchor_close`、`b1_peak_close`、`b1_max_high`、`b1_move_atr`；
- `b1_status`、`b1_frozen_on`、`b1_freeze_reason`；
- `b1_path_efficiency`、`b1_mean_close_location`、`b1_mean_overlap`；
- `b1_max_consecutive_up_bars/start/end`；
- `cycle_peak_date`、`cycle_peak_close`、`cycle_peak_high`；
- `pullback_cycle`、`pullback_start_date`、`pullback_bars`；
- `h1_candidate_today`、`h1_clv`、`h1_breakout_pct`；
- `last_h1_date`、`touch25_manual`。

## 8. 验证要求

- H1 前必须至少有一个完整回调交易日；
- B1 只能在首次收盘回调前延伸，冻结后所有 B1 字段不得改变；
- 首次回调日的盘中高点不得进入 B1；
- 后续新高只更新周期峰值；
- 同一回调周期只产生第一次 H1；
- 收盘创新高后，新回调可以产生下一次 H1；
- touch25 不参与 H1 门控；
- H1 历史查询不重复每日快照；
- 回调阶段互斥且合计不重复；
- 优先观察只使用公开的第一腿质量阈值；
- 指定缺失日期不回退；
- 严格按 as-of/PIT 计算，不读取未来交易日；
- 页面无跨方法总分、无自动买卖措辞。
