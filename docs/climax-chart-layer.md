# 个股扩张与衰竭图层

版本：`climax-system-kc-v1`。所有沪深普通A股收盘后统一计算，在任意个股日线中按需开启；无独立事件查询页，不改变三套方法或两法交集，不生成买卖指令。L4不在本次范围。

## 口径与交互

- 全图仍只有原KC：EMA20 / Wilder ATR20 / 2.35，复用 `charting.keltner_channels`。日线KC初始化使用完整可用历史，不受“一年/全部”可见窗口影响。
- 通道外整根K线按上述KC判断；其他指标按报告事前ATR（此前20日TR简单平均，不含当天），非KC EMA以有效收盘均值初始化，未知报价重置。A0及背景在起点冻结。
- 保留报告的背景、加速、延伸、三种证据择一、由假变真、20市场日冷却及10市场日L3规则。明确的资格缺失不登记候选；市场日历不能压缩为个股有报价日期。
- 开关默认关闭，浏览器记忆偏好；不修改KC显示或参数。自定义KC时提示计算口径，并可恢复默认参数；不显示第二条通道。
- 默认标起点与确认。点击标记或图下事件选择项后，展示尝试点、数值、条件、时间线及截至所选日期的价格变化；参考线需主动开启，仅包含起点收盘和形态参考高点。与既有买卖标记共存。
- 日周线切换时，周线禁用并隐藏本图层。图表数据返回前按截止日期裁剪事件与时间线，参考价格映射到图中复权尺度。
- 历史数据是重建口径，不声称完整PIT认证；ST覆盖要求源ST当日记录或成功日采集凭证。未知、停牌、窗口结束分别表达。当前版本改变了研究KC，不能引用原报告发生率作为个股预测。

## 运行与迁移

使用项目虚拟环境；先显式迁移，再计算：

```sh
.venv/bin/python -m master_stock_selector.watchlist.climax_service --migrate --apply
.venv/bin/python -m master_stock_selector.watchlist.climax_service --apply
```

支持 `--market-database`、`--watchlist-database` 和 `--date`。仅后台采集/计算维护，不是产品展示入口。每日闭环已经接入；未迁移时会在采集前给出明确错误。

迁移仅添加观察结果库的 `climax_stock_document`、`climax_run` 两张表；现有数据库先用SQLite在线备份生成同目录带时间戳的完整备份。行情库和用户库不写入。

每股压缩保存按市场日排列的指标和事件时间线；按版本/股票索引读取，避免打开图表扫描全市场。追加日重新计算并校验全部已保存事实前缀；历史改写时拒绝更新，要求另库/另版本重建。完整批次单事务提交，失败全部回滚。同日重跑校验源修订信息后复用，计算前后核对源文件修订信息。

**发布须单独授权。** ECS应先在其现有观察结果库迁移并使用线上行情计算，不上传本地运行数据库。回滚优先恢复旧代码并保留未使用的新表，避免覆盖线上运行数据；数据恢复只在明确范围、停写并核实无新增数据时使用对应备份。迁移不会删除或改变既有表。
