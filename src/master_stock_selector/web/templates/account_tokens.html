安全边界

Token 不是网站密码

02 · CLI 接入

三步连接 Agent

先验证身份，再预检交易；只有显式添加 --commit 才会写入。

默认不写入
  1. 01安全加载凭据

    CLI 默认连接 longchangwudao.cn；只需把 Token 注入当前终端会话，不写入命令历史。

    read -s MASTERSTOCK_AGENT_TOKEN
export MASTERSTOCK_AGENT_TOKEN
.venv/bin/masterstock agent me
  2. 02预检交易文件

    检查字段、重复记录和可卖数量，不写入系统。

    .venv/bin/masterstock agent trades validate trades.json
  3. 03确认后提交并核验

    提交使用稳定幂等键，网络重试不会重复创建同一批交易。

    .venv/bin/masterstock agent trades import trades.json --commit
.venv/bin/masterstock agent trades list --symbol 600988.SH
查看交易 JSON 示例与止损命令

交易文件

{
  "trades": [{
    "symbol": "600988.SH",
    "traded_on": "2026-08-06",
    "traded_at": "09:30:24",
    "side": "BUY",
    "quantity": 1000,
    "price": 43.18
  }]
}

更新既有 BUY 止损

.venv/bin/masterstock agent trades set-stop \
  EXECUTION_ID 37.56 --expected-revision 1 --commit

该命令只修改匹配 BUY 的止损价；版本冲突时会拒绝更新，不会创建新 BUY 或 SELL。
